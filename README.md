Heart Disease Prediction Using Machine Learning

Project Overview

This project was developed as part of my undergraduate Python coursework. It uses machine learning to predict heart disease based on selected health-related parameters entered by the user.

Features

Data preprocessing and analysis using Python.
Machine learning model development in Jupyter Notebook.
A graphical user interface (GUI) for entering health-related parameters.
A trained model and scaler used for prediction.

Technologies Used

Python
Jupyter Notebook
Machine Learning
Pandas and NumPy
Scikit-learn
Tkinter

Project Files

Python_project.ipynb — Jupyter Notebook containing the project workflow.
heart_gui.py — GUI application source code.
heart_model.pkl — Saved trained machine learning model.
scaler.pkl — Saved data scaler.
background.jpg — GUI background image.
